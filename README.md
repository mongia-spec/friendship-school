# مدرسة الأصدقاء – سرّ الكتاب المخفي

## التشغيل
- افتحي `index.html` بالنقر المزدوج في Chrome أو Edge. لا تحتاج اللعبة تثبيتًا ولا إنترنت
  (الخط العربي المزخرف يُحمَّل من الإنترنت إن توفّر، وإلا يُستعمل خط Tahoma).
- أو شغّلي خادم التجربة: `node game/tools/serve.mjs` ثم افتحي http://localhost:8123

## الملفات
| الملف | ما فيه |
|---|---|
| `content/level1.js` | **كل النصوص والأسئلة**: الحوارات، صفحات القصة، ألغاز الجسر، جملة التعويذة. عدّليه لتغيير الدرس. |
| `js/game.js` | كود اللعبة (Three.js) |
| `js/audio.js` | المؤثرات والموسيقى (مولَّدة في المتصفح، بلا ملفات) |
| `css/style.css` | الواجهة العربية RTL |
| `assets/` | صور الشخصيات المرجعية. `sprites.js` يُولَّد بالأمر `node game/tools/make-sprites.mjs` |
| `vendor/three.min.js` | مكتبة Three.js r149 (مجانية، رخصة MIT) |

## التحكم
WASD أو الأسهم للمشي · Shift للجري · المسافة للقفز · E للتفاعل · السحب بالفأرة أو Q/R لتدوير الكاميرا · Esc للإيقاف.
على الهاتف: عصا تحكم وأزرار تظهر تلقائيًا.

## التقدّم
يُحفظ تلقائيًا في المتصفح (localStorage) عند كل مرحلة، ويظهر زر «متابعة من آخر نقطة».

## مؤقت حتى تصل الصور
- الأصدقاء الستة: أشكال مؤقتة عليها «؟» و«صورة مؤقتة».
- اللاعب: شخصية عامة مبنية من أشكال بسيطة.
